# Modelagem de Sistemas Computacionais ![UML](https://img.shields.io/badge/UML-Unified%20Modeling%20Language-blue?logo=uml&logoColor=white)

## Sobre o repositório

Este repositório reúne os **diagramas UML** (*Unified Modeling Language* — Linguagem de Modelagem Unificada) e os **projetos que foram modelados** ao longo do estudo e desenvolvimento de sistemas computacionais.

Vários projetos são modelados neste espaço, cada um com suas regras, fluxos, estruturas e interações documentados por meio de diagramas UML, permitindo visualizar o funcionamento dos sistemas antes ou durante a implementação.

## Objetivos

- Reunir os vários projetos modelados e seus respectivos diagramas UML em um único lugar.
- Representar visualmente a estrutura, o comportamento e a interação entre os componentes de cada sistema.
- Aplicar os conceitos da UML em diferentes cenários e propostas de projetos.
- Documentar requisitos, processos, funcionalidades e arquitetura dos sistemas modelados.
- Registrar a evolução prática em análise e modelagem de sistemas.

## Diagramas UML

Os projetos modelados neste repositório utilizam diferentes tipos de diagramas UML conforme as necessidades de cada sistema, incluindo:

- **Diagrama de Casos de Uso:** representa as funcionalidades do sistema e a interação dos atores com essas funcionalidades.
- **Diagrama de Classes:** apresenta as classes, seus atributos, métodos e relacionamentos.
- **Diagrama de Objetos:** representa instâncias de classes e seus relacionamentos em determinado momento.
- **Diagrama de Sequência:** demonstra a troca de mensagens entre objetos ao longo do tempo.
- **Diagrama de Atividades:** representa fluxos de processos, ações e decisões.
- **Diagrama de Estados:** descreve os estados de um objeto e as transições entre eles.
- **Diagrama de Componentes:** representa os componentes de software e suas dependências.
- **Diagrama de Implantação:** demonstra a distribuição dos componentes de software nos elementos físicos ou ambientes de execução.
- **Diagrama de Pacotes:** organiza os elementos do sistema em grupos e apresenta suas dependências.
- **Diagrama de Comunicação:** representa as interações entre objetos com foco em suas conexões e mensagens.
- **Diagrama de Visão Geral da Interação:** apresenta uma visão geral dos fluxos de interação entre diferentes partes do sistema.
- **Diagrama de Tempo:** demonstra as mudanças de estado e as interações considerando o tempo.

Outros diagramas e artefatos de modelagem podem ser adicionados conforme novos projetos forem modelados.

## Projetos modelados

O repositório conta com diversos projetos modelados que abrangem diferentes contextos, como sistemas de gerenciamento, plataformas de cadastro, sistemas acadêmicos, aplicações empresariais e outras soluções computacionais.

Cada projeto possui seus próprios requisitos e características, reunindo os diagramas UML mais adequados para representar seu domínio e comportamento.

## Ferramentas utilizadas

Para a elaboração dos diagramas e organização do repositório, são utilizadas ferramentas de modelagem UML, além do **Git** e do **GitHub** para versionamento e compartilhamento dos projetos modelados.

## Considerações finais

Este repositório centraliza os projetos modelados e os diagramas UML produzidos para cada um deles, servindo como referência prática de análise, estruturação e documentação de sistemas computacionais.
