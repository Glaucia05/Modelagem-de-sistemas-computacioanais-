# Sistema de Empréstimo de Livros — Modelagem UML

## Sobre o projeto

Este projeto consiste na modelagem de um **Sistema de Empréstimo de Livros**, desenvolvido como parte de um trabalho acadêmico da disciplina de Modelagem de Sistemas Computacionais, do curso de Bacharelado em Ciência da Computação da PUCPR.

O objetivo é representar a estrutura, as funcionalidades e os processos de um sistema de gerenciamento de empréstimos de livros por meio de diagramas UML (Unified Modeling Language), permitindo visualizar e documentar diferentes aspectos da solução proposta.

Esta publicação corresponde à **primeira etapa do projeto**. A modelagem será ampliada posteriormente, com a inclusão de novas etapas, diagramas e demais elementos que complementarão a documentação do sistema.

## Modelagens desenvolvidas

Nesta primeira etapa, foram elaborados os seguintes diagramas:

- **Diagrama de Casos de Uso:** apresenta as funcionalidades do sistema e as interações dos atores com as operações disponíveis.
- **Diagrama de Domínio:** representa os principais conceitos do sistema e os relacionamentos entre as entidades envolvidas.
- **Diagramas de Sequência:** representam as interações entre os elementos do sistema durante a execução de operações específicas.
- **Diagrama de Classes de Projeto:** apresenta a estrutura do sistema, incluindo classes, atributos, métodos, interfaces e relacionamentos.

## Funcionalidades representadas

A modelagem contempla diferentes operações relacionadas ao gerenciamento de pessoas, usuários e livros, incluindo:

- Manutenção de pessoas, estudantes e atendentes.
- Manutenção e consulta de livros.
- Solicitação e consulta de reservas.
- Realização e efetivação de empréstimos.
- Renovação de empréstimos.
- Registro de devoluções.
- Emissão de boletos de multa.
- Cálculo de multas relacionadas aos empréstimos.

Essas funcionalidades são representadas por meio dos diagramas desenvolvidos nesta etapa, de acordo com a perspectiva de cada modelo.

## Organização do projeto

Os arquivos disponibilizados neste momento reúnem as modelagens UML produzidas para o sistema de empréstimo de livros.

Conforme o desenvolvimento avançar, novas partes serão adicionadas ao repositório, complementando a documentação e ampliando a representação do sistema.
